Usa este formato:

- Tema: enemigo | skill | hechizo | herramienta

- Contexto de escena:
- Objetivo del PJ:
- Restricciones (PG, PV, estado, distancia, luz):
- Pregunta exacta:

Ejemplo:

"Tema: hechizo. Nombre exacto: Muro de piedra. Contexto: pasillo estrecho con 3 orcos avanzando. Objetivo: bloquear 2 rondas para huir. Restricciones: mago con PV bajos. Pregunta exacta: conviene este hechizo o Escudo de piedra y por que?"
